# Codex 0.159.3 原生推理验收（2026-10-02）

## 范围

本次验证新版 Codex 用于 Ambient 主/快速模型的传输兼容性。执行环境为实际 Linux
Debian 12 aarch64 容器、官方固定 `codex-cli 0.159.3`。适配器和探针位于容器临时目录，
未替换运行服务代码、重启服务或修改模型绑定。

探针使用独立推理 home、项目外临时 cwd、ephemeral thread、read-only/no-network 策略，
只通过受信 `auth.json` 链接共享现有 CLI 托管登录。没有读取或复制认证内容，没有发送
工作区数据。文本与工具选择各设 60 秒上限；工具选择仅验证 JSON，没有执行工具。

先以无认证、零模型请求的实际 CLI 探针验证 `initialize` 与 `config/read` 的安全配置。
公开固定源码和生成协议形成 `tests/fixtures/codex_native_0_159_3.json`；fixture 只包含模型
元数据及配置投影，不含账户信息。协议适配遵循 [Provider 契约](../integrations/llm-providers.md)。

实际生成使用精确 `gpt-6-luna`，通过生产 `NativeCodexTransport.generate` 解析结果：

| 探针 | 验证结果 | 输入/输出/总 tokens |

另以零模型请求的独立 thread 探针确认启动 warning 精确来自
`skip_host_skill_discovery`，不是通过忽略任意上游警告取得兼容。

## 回归与限制

新版切片先完成实际失败测试，再实现通过；包括四个 GPT-6 型号的严格 JSON、异步消息过滤、
同 ID 类型/delivery 不变、已知账户/警告形状、不支持版本、错误身份、未知工具及配置拒绝。
旧 `0.145.0` profile 仍独立回归。最终完整后端 1225 通过、16 跳过；前端 358 通过，
构建与 lint 通过。Ruff、UML 与中英文文档校验作为提交前门禁。

新版外部 CodeMode host 保持禁用，不能将此结果描述为已支持内部 CodeMode 执行。
实际生成只验证 `gpt-6-luna`；其他型号仍需按精确选择测试账户访问。
本记录不是完整 App、持久 Run、恢复或公网验收，也不是 Harness 重复评测。
本地源码尚未部署到运行服务；更新后需重新同步模型目录以刷新已保存的用途兼容性。
